# أول خطوة · Awal Khatwa

**فرص التدريب ووظائف المبتدئين في الشركات الناشئة السعودية، في مكان واحد.**

🔗 **الموقع:** https://saraalzhrani7.github.io/Awal-khatwa/

![أول خطوة](og-image.png)

## المشكلة

فرص حديثي التخرج موجودة، بس مشتتة بين صفحات توظيف الشركات ولينكدإن وقنوات تيليجرام. وكثير من البرامج يقفل التقديم عليها قبل ما أحد يدري عنها. «أول خطوة» يجمعها في صفحة وحدة، ويتحدث تلقائيًا كل يوم.

## وش فيه؟

- **الفرص:** تدريب، وتعاوني، وبرامج خريجين، ووظائف Entry Level، مع فلترة حسب النوع والمجال والمدينة، وعداد لآخر موعد للتقديم، وشارة للإعلانات الجديدة، وزر مشاركة لكل فرصة
- **الشركات:** دليل لأكثر من 50 شركة ناشئة سعودية، فيه روابط صفحات التوظيف
- **سيرتك:** صانع سيرة ذاتية مجاني بقالب متوافق مع أنظمة ATS، يحملها PDF، ويطابقها مع وصف أي وظيفة. كل البيانات تبقى في جهاز المستخدم
- **دليل المبتدئ:** الفرق بين أنواع الفرص، والسيرة الذاتية لأول وظيفة، ومتى تفتح البرامج كل سنة
- **الإحصائيات:** أكثر الشركات توظيفًا للمبتدئين، وأكثر المجالات طلبًا، وعدد الفرص عبر الوقت

## طريقة الشغل

```
GitHub Actions (يوميًا 6 الصبح بتوقيت السعودية)
        │
        ▼
scripts/update_jobs.py
  ├─ يجيب الإعلانات من واجهات أنظمة التوظيف العامة:
  │    Workable · Greenhouse · Ashby · Pinpoint · SmartRecruiters
  ├─ يفلتر: السعودية فقط + مناسبة للمبتدئين
  │    (Intern, Junior, Graduate, Co-op, Entry Level, تمهير…)
  ├─ يصنّف النوع والمجال، ويدمج الإعلان المكرر في أكثر من مدينة
  ├─ يحافظ على الإعلانات اليدوية والتعديلات اليدوية
  └─ يكتب data/listings.json + سجل يومي في data/history.json
        │
        ▼
GitHub Pages ← index.html / guide.html / stats.html
```

- **بدون خادم وبدون قاعدة بيانات:** موقع ثابت (HTML + CSS + JavaScript) يقرأ ملفات JSON.
- **يتحمل الأعطال:** إذا فشل الاتصال بشركة، تبقى إعلاناتها السابقة زي ما هي.
- **ما يتعارض مع التعديلات:** لو انرفع تعديل أثناء التشغيل، السكربت يسحبه قبل ما يرفع.

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | صفحة الفرص والشركات |
| `cv.html` | صانع السيرة والمطابقة مع الإعلان |
| `guide.html` | دليل المبتدئ |
| `stats.html` | الإحصائيات |
| `data/listings.json` | كل الإعلانات. التلقائية عليها `"source": "auto"` |
| `data/history.json` | سجل يومي لعدد الفرص (للإحصائيات) |
| `scripts/update_jobs.py` | سكربت التحديث (Python، بدون مكتبات خارجية) |
| `.github/workflows/update-jobs.yml` | التشغيل اليومي |

## إضافة شركة للتحديث التلقائي

في `scripts/update_jobs.py`، أضف سطر لقائمة `SOURCES`:

```python
{"company": "اسم الشركة", "companyEn": "Company", "ats": "workable", "id": "company-slug"},
```

`ats` يكون واحد من: `workable` · `greenhouse` · `ashby` · `pinpoint` · `smartrecruiters`

## ملاحظة

«أول خطوة» مشروع مستقل وغير تابع لأي من الشركات المذكورة. كل الإعلانات مأخوذة من صفحات التوظيف الرسمية، وكل إعلان يودي لصفحة التقديم الأصلية.
